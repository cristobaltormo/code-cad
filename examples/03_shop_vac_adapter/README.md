# 03 - Shop-vac hose reducer

36 mm hose cuff to 31 mm tool port with 1.5 deg friction tapers and a lofted
transition, 2.4 mm walls, 0.8 mm entry chamfers. Prints vertically with no
supports. Vacuum fittings are not standardised: measure yours.

```bash
./bin/cad build examples/03_shop_vac_adapter
```
