# 06 - Gridfinity bin 2 x 1 x 3U

`cad_tools.gridfinity.gridfinity_bin()` - feet and body as one solid, open
cavity (1.2 mm walls, floor at 7 mm), Ø6.5 x 2.4 magnet pockets. Values
verified against gridfinity-rebuilt (`cad lookup gridfinity`). The v0.1 helper
produced 5 disconnected solids with the body floating above the feet.

```bash
./bin/cad build examples/06_gridfinity_bin
```
